# 003: Diagram review as a page variant, fed by Graphviz SVG

Date: 2026-11-15. Status: built (v0.5.0).

**Need.** Review an architecture diagram (first case: the Canopy posters,
`Canopy/docs/diagrams/{home,cloud}-canopy.dot`, generated by `build.py`) by commenting on
individual boxes, connections and zones, not on a flat list.

**Decision.**
- Input is Graphviz source, not the PDF. One `dot -Tsvg -Tjson0` run gives the drawing and the
  structure (cluster membership) from the same layout. The SVG's `<title>` per `<g class="node|edge|cluster">`
  is the element's name in the `.dot`, so item ids map back to the source exactly.
- The SVG is embedded in items.json (`diagrams[].svg`, ~70 KB per poster plus embedded fonts), so
  the server needed no new route; `new` copies `panel/diagram.html` as the session page when items
  carry `diagrams`.
- Answers stay ordinary choice items, so `result`, `wait`, `outcome`, `save` work unchanged.

**Ruled out.** Parsing the PDF (no element identity); a JS Graphviz renderer in the page (needs a
CDN or a vendored wasm blob, and the layout would drift from the printed poster); serving SVG files
from the session dir (an extra route for no gain).

**Gotcha.** Without the poster fonts, `dot` measures with a fallback font and labels overflow. Pass
`--font-dir` (the Canopy fonts are in `docs/diagrams/fonts/`).
